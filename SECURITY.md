# Security Policy

## Supported versions

Only the latest published release receives security updates. Upgrade to the
newest semantic-versioned image before reporting a problem.

## Reporting a vulnerability

Use the private vulnerability reporting form at
`https://github.com/dwightmulcahy/hvac-dashboard/security/advisories/new`. If
private reporting is unavailable, open an issue requesting a private contact
channel without including exploit details, credentials, tokens, private URLs,
or screenshots.

Include the affected version, deployment (Docker host / kiosk), impact, and
minimal reproduction steps. Do not test against systems you do not own or have
permission to assess.

Never commit credentials, access tokens, `.env` files, `secrets.yaml`,
`data/` state files, or diagnostic captures containing private information.
